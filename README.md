# 👁️ 3rd Eye Singapore

Real-time crowd-sourced incident reporting and LTA data integration for Singapore.

## Features
- 📍 Interactive map with incident markers
- 📸 Photo/video upload for reports
- 🙋 Post & respond to information requests
- 🚌 LTA Bus Arrivals
- 🚇 LTA Train Alerts  
- 🚗 LTA Traffic Updates
- 🌊 LTA Flood Alerts
- 👥 LTA Crowd Density
- 🚕 LTA Taxi Availability
- 🎵 TikTok-style crowd feed
- ⏱️ Time filters (30min - 3 days)
- 🏷️ Category & location filters
